SOCKBUSTER — EVALUACIÓN 3 (INACAP)
==================================

¡Este proyecto está preparado para abrirlo en Visual Studio Code!

PASO 1: Descomprime la carpeta completa y ábrela en Visual Studio Code.
PASO 2: Abre js/students.js y REEMPLAZA el texto de ejemplo por tu nombre completo
        y el de cada compañero. Guarda con Ctrl + S.
PASO 3: En VS Code instala la extensión Live Server, haz clic derecho en
        index.html y selecciona "Open with Live Server".
PASO 4: Prueba los enlaces Inicio / Catálogo / Arquitectura 4+1. En Catálogo
        prueba carrito, compra simulada y reseñas.
PASO 5: Sube TODOS los archivos y carpetas a un repositorio GitHub PUBLICO,
        habilita GitHub Pages y reemplaza TU_USUARIO en README.md por tu usuario.
PASO 6: Entrega en INACAP la URL del repositorio GitHub, NO solo el archivo ZIP.

Supabase de README.md (schema.sql + Autenticación JWT + RLS).
